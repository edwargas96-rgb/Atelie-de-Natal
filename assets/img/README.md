# Imagens (fornecidas pelo Eduardo, em WebP)

Enquanto o arquivo não existe, a página mostra um quadro de espaço reservado.

| Arquivo | Uso |
|---|---|
| `mockup-hero.webp` | Mockup do hero (quadrada, ~1000×1000); sem o arquivo aparece um quadro "Mockup em breve" |
| `bonus-1.webp` … `bonus-5.webp` | Capas dos 5 bônus (quadrada) |
| `sessao-1.webp` … `sessao-4.webp` | Mockups das 4 sessões (quadrada) |
| `og.jpg` (1200×630) | Imagem de compartilhamento (WhatsApp/Facebook preferem JPG/PNG) |

Amostras de molde (uma por presente) ficam em `assets/amostras/`: `amostra-N.pdf` e `amostra-N.webp` (N = 1 a 6).
